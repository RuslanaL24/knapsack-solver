# 0/1 Knapsack Solver

Реализация классической задачи о рюкзаке (0/1 Knapsack Problem) на Python
с использованием динамического программирования.

## О задаче

Дано множество предметов, у каждого есть вес и ценность. Есть рюкзак
с ограниченной грузоподъёмностью. Нужно выбрать такое подмножество
предметов, чтобы их суммарная ценность была максимальной, а суммарный
вес не превышал вместимость рюкзака.

Условие «0/1» означает, что каждый предмет можно взять либо целиком
один раз, либо не брать вовсе (дробить предметы нельзя).

## Алгоритм

Используется метод динамического программирования:

- `dp[i][w]` — максимальная ценность, которую можно получить,
  используя первые `i` предметов при вместимости `w`.
- Переход: для каждого предмета либо берём его (если помещается),
  либо не берём — выбираем максимум.
- После заполнения таблицы выбранные предметы восстанавливаются
  обратным проходом.
